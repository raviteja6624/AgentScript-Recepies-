# AgentScript Recipes

Comprehensive collection of recipes and examples for building with Agent Script.

## Getting Started

This repository contains various recipes and examples organized by category:

- **Language Essentials**: Core language features and patterns
- **Action Configuration**: How to configure and chain actions
- **Service Agents**: Service-specific agent implementations
- **Future Recipes**: Advanced patterns and upcoming features
